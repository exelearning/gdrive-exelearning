Privacy Policy

gdrive-exelearning · Last updated: 2026-05-10

This Privacy Policy explains how gdrive-exelearning handles personal data and content when you use the application. The application is a free open-source web tool published by the eXeLearning project, distributed under the GNU Affero General Public License v3.0 or later (AGPL-3.0+).

1. Summary in plain language

  • The application runs entirely in your browser. We do not operate any backend server that receives your content.
  • We do not collect analytics, telemetry, or tracking data.
  • We do not use cookies for tracking. The only browser storage used is whatever the Google Identity Services library temporarily stores during the OAuth flow.
  • Your .elpx files stay in your own Google Drive.
  • You can revoke access at any time at myaccount.google.com/permissions.

2. Data the application processes

The application processes only the minimum data required to let you open and save your eXeLearning files:

Category Source Where it lives Retention
Google account identifier (email, name, profile picture) Google Identity Services after you sign in In the memory of your browser tab Discarded when the tab closes
OAuth access tokens Issued by Google to call the Drive API on your behalf In the memory of your browser tab Expires after ~1 hour, never persisted on disk
The .elpx files you choose to open Your Google Drive (via Drive API, drive.file scope) Read into your browser memory while you edit Saved back to your own Drive when you save; never copied elsewhere
HTTP server logs of GitHub Pages Generated automatically by GitHub when serving the static site GitHub infrastructure Governed by the GitHub Privacy Statement

3. What we do NOT do

  • We do not transmit your .elpx content or Drive metadata to any server controlled by the eXeLearning project.
  • We do not store refresh tokens. Each session uses a short-lived access token issued by Google.
  • We do not run analytics, tracking pixels, or third-party advertising scripts.
  • We do not sell, share, or otherwise disclose your personal data to third parties.
  • We do not access any file in your Drive that you have not explicitly opened or created with the application (drive.file scope).

4. Google API user data

The application’s use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Specifically:

  • Data accessed via the Drive API is used only to provide the user-facing functionality of opening, editing, and saving .elpx files.
  • Data is never used to develop, improve, or train generalized or non-personalized AI/ML models.
  • Data is not transferred to any third party for purposes unrelated to the user-facing features the user requested.
  • Data is not used or transferred for purposes such as advertising or credit-worthiness.
  • Humans do not read your data unless you explicitly grant permission for a specific support request.

5. Hosting

The application is served as static files from GitHub Pages. GitHub may collect standard HTTP server log information (such as IP address and user agent) when you load the page. Their handling of that data is governed by the GitHub Privacy Statement. The eXeLearning project does not have access to those logs.

6. Your rights

Because the application does not store your personal data on any infrastructure operated by the eXeLearning project, there is no central record to access, rectify, export, or delete on our side. To exercise data-subject rights:

  • Revoke access at myaccount.google.com/permissions. This immediately stops the application from accessing your Drive on your behalf.
  • Manage data held by Google through your Google Account data & privacy settings.
  • Contact us via the project issue tracker for any privacy-related question.

7. Children and educational use

gdrive-exelearning is intended for use by educators and learners. The application itself does not request, collect, or process information about children separately from the Google account used to sign in. When the application is deployed in an educational setting that involves minors, the educational institution remains the data controller and is responsible for any consent, parental notification, and record-keeping required by applicable laws (such as GDPR or COPPA).

8. Security

The application uses HTTPS to transport data between your browser and Google’s APIs. OAuth access tokens are kept only in browser memory and are never written to disk by the application. Source code and security-relevant changes are public and auditable in the project repository. Security disclosures may be opened privately via the GitHub security advisories page.

9. Changes to this Policy

This Privacy Policy may be updated from time to time. The “Last updated” date at the top reflects the most recent revision. Material changes will be highlighted in the project changelog.

10. Contact

For privacy questions or data-subject requests, please open an issue at github.com/exelearning/gdrive-exelearning/issues or reach the maintainers through the eXeLearning project website.

By using gdrive-exelearning you confirm that you have read this Privacy Policy and understand how your data is processed.
